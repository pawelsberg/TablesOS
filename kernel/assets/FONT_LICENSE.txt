TablesOS bundled font atlas — attribution and license
=======================================================

The file `font.png` in this directory is a monospace glyph atlas (a bitmap
rendering, white-on-black coverage) produced from the **Cascadia Mono**
typeface. It is a Modified Version (a derivative work) of that font and is
distributed here, and embedded in the TablesOS bootable image, under the same
license as the font: the SIL Open Font License, Version 1.1.

  https://github.com/microsoft/cascadia-code
  Licensed under the SIL Open Font License, Version 1.1.

Reserved Font Name (OFL clause 3): "Cascadia Code" is a Reserved Font Name.
This bitmap derivative is NOT presented to users under that name — TablesOS
refers to it only as the "TablesOS glyph atlas", and names "Cascadia" solely
to acknowledge the upstream work (permitted by clause 4). It is not offered as
a font called "Cascadia".

Where the notice and this license travel (OFL clause 2): this file is the
stand-alone text accompanying the source, and its full contents are embedded
in the kernel binary and shown in the OS under **Table List -> [a] About /
Licenses**, so every redistributed copy — source tree or bootable image —
carries the copyright notice and license in a form the user can view.

To regenerate `font.png` from any installed monospace face, see
`ASSET_PROMPTS.md` section 2.3 (the PowerShell one-shot). For a publicly
distributed build, render only from an open-licensed font (e.g. Cascadia Mono,
DejaVu Sans Mono, JetBrains Mono) and ship its license — do NOT commit an atlas
rendered from a proprietary font such as Consolas.
